# `net/` — 网络协议（v0.1 只定形，不接线）

## 这层管什么

二进制快照编解码。**v0.1 不接多人**，只把协议定下来并有测试保证它稳定。

| 文件 | 职责 |
|---|---|
| `protocol.ts` | 二进制快照编码/解码（位置量化、朝向量化、状态位掩码） |
| `protocol.test.ts` | 37 条 round-trip 测试 |

## 为什么 v0.1 不做多人

规格书 §2.3：评委单人点开，"3~6 个会动会说的角色"观感已等同多人。
多人要解决服务端权威、插值、延迟补偿、断线重连——那是 v0.2 的事。

**但协议要先定形**，否则 v0.2 会发现"数据结构不支持量化"，要大改。

## 硬约束（改这里之前必读）

1. **协议是二进制的，不是 JSON**。带宽差 10 倍以上。
2. **位置量化到 int8（×127）**、朝向量化到 int16（×32767/π）。
   精度约 0.008 m / 0.0001 rad，够用且省一半带宽。
3. **改协议必须同步改 `protocol.test.ts` 的 round-trip 用例**。
   37 条测试是协议稳定的唯一保证。
