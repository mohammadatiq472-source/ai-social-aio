# `verify/` — 验收判定逻辑

## 这层管什么

物理验收 P1–P12 的**判定逻辑**（纯函数，可单测）。浏览器驱动在 `tools/verify-physics.mjs`。

| 文件 | 职责 |
|---|---|
| `harness.ts` | P1–P12 的判定与三态输出（PASS / FAIL / SKIP） |

## 为什么判定逻辑和驱动分离

- 判定逻辑纯函数 → 能在 node 单测里验证"判定本身对不对"
- 浏览器驱动只负责"跑场景 + 取数字"
- 分开之后，判定逻辑改错会被单测抓到，不需要每次都开浏览器

## 硬约束（改这里之前必读）

1. **P12 必须三态**。拿不到 `global.gc` 时如实 SKIP，**不判 PASS 也不判 FAIL**。
   否则会得到"有时候过、有时候不过"的假结论（实测：堆增量在 -42KB ~ 16MB 乱跳）。

2. **`VERIFY_TOTAL = 12`**。改这个数字意味着增减验收项，要同步改文档与 README。

3. **判定阈值改小会让验收失去意义**。改之前先问"这个阈值能抓住什么回归"。

## 验收

```bash
node tools/verify-physics.mjs    # 全部通过：12/12
node tools/verify-physics.mjs P6 P11   # 只跑指定项（子集语法已修过 bug）
```

## P1–P12 清单

| 项 | 验什么 |
|---|---|
| P1 | 站立稳定（不抖、不下沉） |
| P2 | 走路位移正确 |
| P3 | 30° 斜坡可上 / 45° 不可上 |
| P4 | 跳跃高度 |
| P5 | 落地稳定 |
| P6 | 跳跃高度精确值（1.1999m） |
| P7 | 5m 落体不穿地 |
| P8 | 冲刺撞墙不穿墙 |
| P9 | 道具可推动 |
| P10 | 斜坡滑落 |
| P11 | 对象池复用 |
| P12 | 内存不泄漏（需强制 GC） |
